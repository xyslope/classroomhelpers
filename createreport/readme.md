# Word文書をひとまとめにするスクリプト
Word文書をひとまとめしてPDF化するときに、いくつか便利な機能をまとめています。

生成時に、タイトルとページ数のリストを出力してくれるので目次を作成する際に楽ができます。

# 使い方
docsディレクトリにWord文書ファイルを入れておく。

1. createfilelist.pyでfilelist.csvを生成する
2. filelist.csvのtoc_textを直接修正する
3. makeindex.pyを実行して目次ファイルを生成する
4. makeThesisBook.pyヲ実行して、一つにまとめたPDFを生成する

## ファイルリストの作成
filelist.csvには目次順にしたがって、ファイル名のリストを入れておく。このファイルは、「file名,タイトル,氏名,ページ数,toc_text」からなっており、
目次を生成するときに、toc_textとページ数が参照される。

createfilelist.pyを使うと、ファイルの一覧を作成できる。タイトル・toc_text列は手動での修正が必要だ。

PDFファイルを製本目的で制作する場合などでは、各文書が偶数ページであると同じ側から始まって都合が良い。createfilelist.pyでは、-bオプションをつけることで、奇数ページの文書の後ろのページに空白ページが追加される。


## 目次の生成
目次ファイルはmakeindex.pyで生成できる。

目次ファイルは自動作成されて、問答無用で上書きされるので、スタイル等を調整したければバックアップを取っておくことを薦める。

filelist.csvを参照して、上から順に目次項目としていく。

表紙やはしがき、目次にはページ番号を入れないことが多い。そんなばあいは、--page_count_fromオプションで、文書番号を指定すればその文書からページ数がカウントされる。目次にもページ番号が付されないようになる。なお、ここでの文書番号は、filelistに記載されている順番で、一番目の文書が0になる。

目次にはローマ数字を入れたいなどの要望には答えられない。そのうち対応するかも知れないけれど、どんな仕様にすると使いやすいのか、想像しにくいので、今は手を付けない。

## 文書を作成する
いよいよ文書を統合して、一つのPDFを作成する。makeThesisBook.pyを起動すれば、filelistに記載された順にPDF化を実施して、最後に一つの文書にまとめてくれる。

filelistを生成する際に-bオプションを付けて、すべてを偶数にする設定にしている場合はここでも-bオプションは必須である。逆も同様だ。これをしないと当たり前だけれど、ページがズレてしまう。

1ページ目からページ番号を入れない設定にしている場合や-psを指定している場合も同じだ。手作業になってもうしわけないが、これらのオプションを同期しておくことで、ページ番号がずれない文書作成が可能になる。

# 主な機能
## 空白ページの追加（-b）
Word文書を統合する際に、すべての文書が奇数はじまりになるように、奇数ページの文書には空白ページを追加します。

同梱のblank.pdfを挿入するので、blank.pdfを別のものに替えてもいいかもしれません。

## PDF化をスキップする（-sc）
WordからPDFを生成するのはちょっと時間がかかるので、一部の文書だけを差し替える場合は、手動でPDF化した方が早いです。
そのばあい、このオプションを使用すれば、PDFの統合だけを行ってくれます。

## 最初のいくつかの文書はページ番号を挿入しない
オプションに-pf=nとすると、最初からn番目の文書までは、ページ番号を挿入しない。

表紙とか目次ページにページ番号を表示したくないときに利用する。

次のpsオプションとあわせて使用すると良い。

## ページ番号をmからはじめる
オプションに-ps=mとすると、ページ番号をmから挿入する。

pfオプションが指定されているときは、最初からnページ目からページ番号が挿入され、番号はmからはじまる。
